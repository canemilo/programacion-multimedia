Este repositorio es mi rincón de prácticas para la asignatura de Programación Multimedia. Aquí vas a encontrar ejercicios de Dart ordenados por relaciones, empezando desde lo más básico y avanzando poco a poco hacia cosas más completas.

No es un proyecto enorme ni ultra formal: es más bien una especie de cuaderno de trabajo donde cada archivo tiene una pequeña misión clara.

##  Qué contiene este proyecto

- [Relación 1](./Ejercicios%20DART/Relacion%201): primeros pasos con Dart, variables, tipos, null safety, condiciones y ejercicios introductorios.
- [Relación 2](./Ejercicios%20DART/Relacion2): ejercicios más completos, con lógica, control de flujo y práctica de programación más estructurada.

##  Relación 1 — los primeros pasos

La primera relación es la base. Aquí se empieza a entender cómo funciona Dart desde cero: imprimir mensajes, declarar variables, trabajar con tipos, manejar nulos y resolver problemas sencillos.

Carpeta: [Relacion 1](./Ejercicios%20DART/Relacion%201)

- [1- holaMundo.dart](./Ejercicios%20DART/Relacion%201/1-%20holaMundo.dart) — el ejercicio clásico de inicio, con una primera toma de contacto con la salida por consola.
- [2- 2tipos-dart.dart](./Ejercicios%20DART/Relacion%201/2-%202tipos-dart.dart) — introducción a los tipos de datos, listas, mapas y conjuntos.
- [3- contastePI.dart](./Ejercicios%20DART/Relacion%201/3-%20contastePI.dart) — práctica con const, final y valores constantes.
- [4- variableNull.dart](./Ejercicios%20DART/Relacion%201/4-%20variableNull.dart) — manejo de variables nulas con null safety.
- [5- triangulo.dart](./Ejercicios%20DART/Relacion%201/5-%20triangulo.dart) — ejercicio de condiciones para saber qué tipo de triángulo es.
- [6- suma-resta-division.dart](./Ejercicios%20DART/Relacion%201/6-%20suma-resta-division.dart) — calculadora básica con operaciones y validaciones.
- [10- primeros n numeros naturales.dart](./Ejercicios%20DART/Relacion%201/10-%20primeros%20n%20numeros%20naturales.dart) — suma de los primeros n números naturales con bucles.
- [11- factorial numero.dart](./Ejercicios%20DART/Relacion%201/11-%20factorial%20numero.dart) — cálculo del factorial, muy útil para practicar repetición y lógica.
- [14- caras de un dado.dart](./Ejercicios%20DART/Relacion%201/14-%20caras%20de%20un%20dado.dart) — simulación de un dado y sus distintas caras.
- [15- lanzar dado n veces .dart](./Ejercicios%20DART/Relacion%201/15-%20lanzar%20dado%20n%20veces%20.dart) — más de lo mismo, pero repitiendo lanzamientos varias veces.
- [pruebaExamen.dart](./Ejercicios%20DART/Relacion%201/pruebaExamen.dart) — archivo de repaso para poner en práctica varios conceptos a la vez.
